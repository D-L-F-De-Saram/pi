# Private De Saram drafting wiki

The ignored `junior-de-saram/private-wiki/` directory contains the initial firm examples: a writ petition, written submissions, a lease agreement and an affidavit. Each Markdown file has an adjacent `.md.json` file with its type, practice area and indexed source record. These are private examples and must not be committed or included in the Docker build context.

Compose mounts this directory read/write at `/data/private-wiki`. Set `JUNIOR_DE_SARAM_WIKI_HOST_PATH` in `.env` to choose the host directory; the default is `./junior-de-saram/private-wiki`. Newly selected firm examples are fetched from the indexed document and file services and saved under `private-wiki/imported/` with a readable title-based filename and adjacent `.md.json` metadata. A short stable suffix is added only if two different sources would have the same filename. Pi searches both the seed files and imported files. The selected full example is saved only when read. The trace records the search/read calls and the draft validation, rendering and publication steps.

On another host, copy the private wiki directory through a secure channel before recreating the container, or create an empty directory and let indexed source fallback populate `imported/`. Set `JUNIOR_DE_SARAM_WIKI_HOST_PATH` in that host's `.env` to the absolute directory path. The container's `node` user (UID 1000) needs read/write access. The source tunnel or server-side internal routes must make `DESARAM_TYPESENSE_URL` and `DESARAM_FILE_SERVER_URL` reachable. The existing `Connect-DeSaramSources.sh` reconnects local SSH forwards after container recreation.

Earlier versions used a named Docker volume with hashed filenames. Its original data is preserved in that volume; a copy is in the ignored `junior-de-saram/private-wiki-cache/` legacy backup on this laptop. `node junior-de-saram/migrate-wiki-cache.mjs <legacy-directory> [wiki-host-directory]` imports those files into the title-named host wiki without deleting the originals. On another host, copy the old volume contents to a legacy directory before switching the Compose mount, then run the same command with the destination host path. A repeated source path reuses the existing imported file.

The private samples are drafting patterns, not legal authorities. Keep their original client details out of new work products. Source access and full tool responses may appear in developer trace logs; restrict access to the logs and private wiki accordingly.
